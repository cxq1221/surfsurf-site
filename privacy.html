隐私政策

生效日期：2026 年 10 月 20 日 · 适用于 Chrome 扩展 SurfSurf

简要说明

SurfSurf 没有开发者服务器，不包含统计、广告或追踪代码。扩展只在你触发翻译（手动翻译、为某个站点开启自动翻译，或启用写作翻译并在支持的编辑器中输入）时读取待翻译文本，并发送到你自己配置的模型接口。

扩展会处理哪些数据

  • 页面正文与写作内容：待翻译的页面文本，以及你在已启用的写作翻译编辑器中输入的内容，会发送到你配置的接口（默认 https://api.deepseek.com），用于返回译文。开发者不会收到这些内容。
  • API key：保存在浏览器的 chrome.storage.local 中，只作为请求头发送给你配置的接口，不会上传给开发者。
  • 设置：目标语言、显示方式、自动翻译站点、模型名称等，保存在本地浏览器。
  • 翻译缓存：译文保存在浏览器 IndexedDB 中，30 天有效、上限 50 MB，可在设置页一键清除。
  • 写作历史：只保存最近 20 条已发送的中英对照，可在设置页清除；未发送草稿不落盘。

不会收集的数据

不读取密码、搜索框、单行输入框、Cookie 或浏览历史；不会在你没有点击发送时提交内容。开启“发送时自动替换”后，扩展会拦截你这一次发送，先写回译文，再重放原按钮点击或表单提交；不收集姓名、邮箱、位置、健康、金融等个人信息，也不向第三方出售或共享数据。

第三方接口

翻译请求会直接发送到你配置的模型服务（默认 DeepSeek）。该服务对数据的处理受其自身隐私政策约束。如果你把 Base URL 改成其他服务，页面文本会发送到该地址。

权限说明

  • storage：保存设置与本地缓存。
  • https://api.deepseek.com/*：向默认模型接口发送翻译请求。
  • 内容脚本（所有网站）：在你触发翻译时读取页面正文并在原位渲染译文；写作翻译启用时，读取受支持的多行评论/正文编辑器内容。

数据保留与删除

设置与缓存都保存在本地。卸载扩展或在设置页清除缓存即可删除；开发者不保留任何副本。

Privacy Policy

Effective date: October 20, 2026 · Chrome extension SurfSurf

Summary

SurfSurf has no developer-operated server and contains no analytics, ads or tracking code. The extension reads text only when you trigger translation (manually, by enabling auto translation for a site, or by typing in a supported editor while writing translation is enabled), and sends that text to the model endpoint you configure.

Data processed

  • Page and writing content: page text selected for translation, plus text you type in an enabled writing-translation editor, is sent to your configured endpoint (DeepSeek by default) to produce the translation. The developer never receives it.
  • API key: stored in chrome.storage.local. It is sent only to your configured endpoint as an authorization header, never to the developer.
  • Settings: target language, display mode, auto-translate sites and model name are stored locally.
  • Translation cache: stored in IndexedDB for 30 days, capped at 50 MB, and can be cleared in the settings page.
  • Writing history: only the latest 20 sent bilingual entries are stored locally; unsent drafts are not persisted. You can clear the history in settings.

Data not collected

SurfSurf does not read passwords, search boxes, single-line inputs, cookies or browsing history, and it never submits content without your send action. When auto-replace on send is enabled, it intercepts that user action, writes the translation into the same editor, then replays the original click or form submission. It does not collect personal information or sell or share data with third parties.

Third-party endpoint

Translation requests go directly to the model service you configure (DeepSeek by default), whose own privacy policy applies. If you change the Base URL, page text is sent to that address instead.

Retention and deletion

Settings and cache stay in your browser. Clear the cache in settings or uninstall the extension to delete them. The developer keeps no copy.

隐私政策

生效日期：2026 年 10 月 20 日 · 适用于 Chrome 扩展 SurfSurf

简要说明

SurfSurf 没有开发者服务器，不包含统计、广告或追踪代码。扩展只在你触发翻译（手动翻译，或为某个站点开启自动翻译）时读取页面正文，并把待翻译文本发送到你自己配置的模型接口。

扩展会处理哪些数据

  • 页面正文：待翻译的文本会发送到你配置的接口（默认 https://api.deepseek.com），用于返回译文。开发者不会收到这些内容。
  • API key：保存在浏览器的 chrome.storage.local 中，只作为请求头发送给你配置的接口，不会上传给开发者。
  • 设置：目标语言、显示方式、自动翻译站点、模型名称等，保存在本地浏览器。
  • 翻译缓存：译文保存在浏览器 IndexedDB 中，30 天有效、上限 50 MB，可在设置页一键清除。

不会收集的数据

不读取表单内容、密码、Cookie、浏览历史或输入框内容；不收集姓名、邮箱、位置、健康、金融等个人信息；不向第三方出售或共享数据。

第三方接口

翻译请求会直接发送到你配置的模型服务（默认 DeepSeek）。该服务对数据的处理受其自身隐私政策约束。如果你把 Base URL 改成其他服务，页面文本会发送到该地址。

权限说明

  • storage：保存设置与本地缓存。
  • https://api.deepseek.com/*：向默认模型接口发送翻译请求。
  • 内容脚本（所有网站）：在你触发翻译时读取页面正文并在原位渲染译文。

数据保留与删除

设置与缓存都保存在本地。卸载扩展或在设置页清除缓存即可删除；开发者不保留任何副本。

Privacy Policy

Effective date: October 20, 2026 · Chrome extension SurfSurf

Summary

SurfSurf has no developer-operated server and contains no analytics, ads or tracking code. The extension reads page text only when you trigger translation (manually or by enabling auto translation for a site), and sends that text to the model endpoint you configure.

Data processed

  • Page content: text selected for translation is sent to your configured endpoint (DeepSeek by default) to produce the translation. The developer never receives it.
  • API key: stored in chrome.storage.local. It is sent only to your configured endpoint as an authorization header, never to the developer.
  • Settings: target language, display mode, auto-translate sites and model name are stored locally.
  • Translation cache: stored in IndexedDB for 30 days, capped at 50 MB, and can be cleared in the settings page.

Data not collected

SurfSurf does not read forms, passwords, cookies, browsing history or input fields, does not collect personal information, and does not sell or share data with third parties.

Third-party endpoint

Translation requests go directly to the model service you configure (DeepSeek by default), whose own privacy policy applies. If you change the Base URL, page text is sent to that address instead.

Retention and deletion

Settings and cache stay in your browser. Clear the cache in settings or uninstall the extension to delete them. The developer keeps no copy.
